# How-to guides

Recipes for getting a specific job done. These assume you already know what the
project is and how to run it — if you don't, start with the
[tutorials](../tutorials/index.md).

A how-to answers "how do I *X*?" and nothing else. It does not teach, and it
does not explain why the design is the way it is; that belongs in
[explanation](../explanation/index.md).
