# Tutorials

Lessons that teach by doing. A tutorial takes a newcomer through a complete,
working result, holding their hand the whole way.

A tutorial is not a how-to guide. It is for someone who does not yet know what
questions to ask, so it makes every decision for them, avoids alternatives and
caveats, and always works if followed exactly. Anything that would make a
beginner stop and think belongs elsewhere.

There are no tutorials yet. Add one when someone new needs to be brought up to
speed on this project and a how-to assumes too much.

Meanwhile, see [How-to guides](../how-to/index.md) if you already know the
basics and need to get something done.
